# MemoryMesh Harness

[English](README.en.md)

MemoryMesh는 작업 기록을 남기고 다음 작업에서 이를 읽어 반영하는 파일 기반 작업 연속성 도구입니다. 같은 에이전트의 다음 세션이나 다른 에이전트로 작업을 이어갈 수 있습니다.

## 설치

1. [memorymesh-setup.md](memorymesh-setup.md)를 내려받아 적용할 프로젝트의 최상위 폴더에 넣습니다.
2. 해당 폴더를 열고 에이전트에 다음과 같이 요청합니다.

```text
memorymesh-setup.md 파일의 설정 내용을 이 프로젝트에 적용하라.
```

Codex, Claude Code, Antigravity 등 프로젝트 파일을 읽고 저장할 수 있는 에이전트를 사용합니다. 기본 설치에는 별도 서버나 스킬 설치가 필요하지 않습니다.

에이전트가 기존 설치와 기록을 확인한 뒤 설치 방식을 한 번 묻습니다. 요청에서 방식을 이미 지정했다면 바로 진행합니다.

| 선택 | 처리 내용 |
|---|---|
| 신규 설치 | 필요한 기록과 지침을 구성합니다. |
| 기존 내용 유지하며 반영 | 기존 기록과 사용자 지침을 보존하며 갱신합니다. 기존 설치에 권장합니다. |
| 백업 후 초기화 설치 | 기존 MemoryMesh 구성을 백업한 뒤 다시 구성합니다. |
| MemoryMesh 제거 | 기록을 백업하고 MemoryMesh 전용 구성과 지침을 제거합니다. |
| 취소 | 변경 없이 종료합니다. |

초기화와 제거 시 프로젝트 자료, 사용자 지침의 다른 부분, 외부의 기존 업무 일지와 공용 도구는 보존합니다. 소유권이 불분명한 항목은 남겨 두고 알려줍니다.

## 사용

설치 후에는 평소처럼 작업을 요청하면 됩니다. 다른 에이전트로 이어갈 때도 같은 프로젝트 폴더에서 작업을 시작합니다.

- 새 작업을 시작할 때 이전 기록을 읽고 결정과 제약을 반영합니다.
- 작업 중 중요한 진행 사항을 저장하고, 작업 결과를 답하기 전에 새로 생긴 내용을 기록합니다. 별도의 저장 지시를 반복할 필요는 없습니다.
- 기존 업무 일지가 있으면 그대로 사용합니다. 없으면 `.mesh/work.log`에 기록하며, 현재 상태는 `.mesh/STATE.md`에서 확인할 수 있습니다.

질문, 상태 확인, 답변 요약이나 대화 내용의 목록 정리는 파일을 변경하지 않습니다. 파일 저장이나 기존 기록 갱신을 명시하면 해당 작업을 수행합니다.

## 갱신, 초기화, 제거

새 셋업 파일로 바꾼 뒤 다시 적용해야 설치된 지침이 갱신됩니다. 기존 기록을 유지하려면 다음과 같이 요청합니다.

```text
memorymesh-setup.md를 적용하되, 기존 기록과 사용자 지침을 유지하며 갱신하라.
```

초기화나 제거도 셋업 파일을 통해 요청합니다.

```text
memorymesh-setup.md에 따라 기존 MemoryMesh를 백업한 뒤 초기화 설치하라.
```

```text
memorymesh-setup.md에 따라 MemoryMesh를 제거하라.
```
